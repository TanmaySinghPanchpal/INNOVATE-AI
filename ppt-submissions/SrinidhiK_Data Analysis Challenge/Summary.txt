Entire Project Workflow – Step-by-Step Process and Summary

1. Loaded the Dataset
	Used matches.csv from IPL (2008–2024).
        Checked rows, columns, and data types.

2. Explored the Data
	Described the dataset using .info(), .describe().
        Found the target variable: winner.
        Identified and removed irrelevant columns.

3. Selected Independent Features
	Choose 7 features: team1, team2, venue, city, toss_winner, toss_decision, season.
	These features were known before a match started.

4. Encoded Categorical Data
	Used Label Encoding to convert team names, venues, etc. into numbers.

5. Performed Descriptive Analysis
	Calculated mean, median, standard deviation, min, max, and quartiles.

6. Visualized Data (EDA)
	Plotted:
	 • Count plot for team wins
	 • Histogram for matches per season
	 • Box plot for match venues
	 • Correlation heatmap and pairplot

7. Detected Patterns using Clustering
	Applied StandardScaler for normalization.
	Performed KMeans clustering and visualized using PCA.

8. Model 1 – Decision Tree Classifier
	Splitted data into train/test.
	Trained and evaluated the model.
	Accuracy = 0.52
	Simpler but prone to overfitting.
	Visualized confusion matrix and feature importance.

9. Model 2 – Random Forest
	Retrained model with better generalization.
	Accuracy = 0.70
	More stable but not as accurate as boosting models.
	Visualized confusion matrix and top features.

10. Model 3 – XGBoost Classifier
	Trained and tested using XGBoost.
	Accuracy = 0.86
	Captured complex relationships using gradient boosting.
	Visualized feature importance and model predictions.

11. Model 4 – LightGBM Classifier (Best Model)
	Final model trained and tested using LightGBM.
	Achieved the highest accuracy = 0.90
	Faster and more efficient than XGBoost with better handling of categorical data.
	Confirmed using confusion matrix and feature insights.

12. Final Result
	Project covered full ML pipeline: Loading → Preprocessing → EDA → Modeling → Evaluation.
	LightGBM selected for its superior performance, accuracy, and reliability.

Conclusion: 
	Teams that won the toss and chose to field first had a noticeably higher win rate.
	Certain venues consistently favored specific teams, likely due to pitch conditions and home advantage.
	The model effectively learned from patterns in team combinations and historical performance in those matchups.
	LightGBM handled categorical interactions between teams, city, match_type, and season exceptionally well, enabling precise outcome predictions.

Thus, the model not only predicts match winners accurately but also uncovers strategic insights that align closely with real IPL trends.
Can be extended using player-level or ball-by-ball data for further improvement..
